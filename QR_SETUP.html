WAHA WhatsApp Session Setup

⚠️ Prerequisite: You need a WhatsApp phone number that hasn't been linked to WhatsApp Web/Desktop before. Use a dedicated business number.

1Start WAHA

Run this command in your terminal:

docker run -p 3000:3000 devlikeapro/waha

Keep this terminal window open. You should see: WhatsApp API is running on: http://[::1]:3000

2Create Session

Open a new terminal window and run:

curl -X POST http://localhost:3000/api/sessions -H "Content-Type: application/json" -d '{"name": "default"}'

Or open in browser: http://localhost:3000

3Get QR Code

Run this command:

python3 generate_qr.py

This will create waha_qr.png in your current folder.

📷 QR Code will appear here after running generate_qr.py

📱

4Scan with WhatsApp

  1. Open WhatsApp on your phone
  2. Go to Settings → Linked Devices
  3. Tap Link a Device
  4. Scan the QR code from waha_qr.png

5Verify Connection

After scanning, verify the session is active:

curl http://localhost:3000/api/sessions

You should see "status": "STARTED" or "status": "WORKING".

6Send Test Message

Send a WhatsApp message to your linked number from another phone:

curl -X POST http://localhost:3000/api/sendText -H "Content-Type: application/json" -d '{"session": "default", "chatId": "966500000000@c.us", "text": "Hello from MassageVIP!"}'

Replace 966500000000 with the phone number you used for QR scanning.

✅ You're live! Your WhatsApp number is now connected to MassageVIP Automation. Any incoming messages will be processed by the AI pipeline.

Next Steps

After confirming the QR scan works:

  1. Deploy the automation worker to Render or your server
  2. Set WAHA_BASE_URL to point to your WAHA instance
  3. Configure webhook in WAHA: WHATSAPP_HOOK_URL=http://your-worker:8080/webhook
  4. Monitor /dashboard for incoming leads
